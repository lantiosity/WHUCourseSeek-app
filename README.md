# 珞珈课寻

武汉大学全校课表检索 · **Windows 桌面版（便携版）**

> **适用平台：Windows x86_64（Windows 10 / 11 64 位）**。本仓库只发布可运行的程序与加密数据，**不包含源码**。

- 双击 `珞珈课寻.exe` 即可运行：原生窗口、无需安装、无需 Python、无需启动本地服务器
- 数据库在磁盘上始终是密文，程序启动时才在内存中解密，**明文不落盘**
- 数据范围：2021-2022 第1学期 ～ 2026-2027 第1学期

## 下载与运行

**方式一（推荐）**：到 [Releases](https://github.com/lantiosity/WHUCourseSeek-app/releases/latest) 下载
`WHUCourseSeek-v1.1.2-win-x86_64.zip`（15.8 MB，SHA256 `1DBA9B9093C80A2438F52745CF3FDFE7774050858F73A4708E8F74E09752132B`），解压到任意目录，双击 `珞珈课寻.exe`。

**方式二**：直接在本仓库下载 `珞珈课寻.exe` 和 `data/kebiao.db.enc`（保持 `data` 目录结构），
放进同一个文件夹后双击运行。**不需要任何 DLL**——程序是静态链接的单文件，无 .NET 依赖。

## 首次启动

首次运行会要求**登录智慧珞珈**：程序内嵌的页面就是学校官方的统一身份认证页
（cas.whu.edu.cn），用账号密码 / 动态码 / 智慧珞珈 APP 扫码登录均可。

登录成功后程序会**自动完成初始化**，生成与本机绑定的配置文件 `data/conf.bin`，
**之后启动不再登录、不再询问**。若自动初始化未能完成（例如网络不通），程序会弹出输入框，
此时向维护者索取**当天的恢复代码**粘贴进去即可（恢复代码当天有效）。

程序不接触也不保存账号信息：

- 账号、密码、验证码都在学校官方页面里输入，程序不注入脚本、不读取页面内容；
- 浏览器内核以**无痕模式**运行，Cookie、会话只存在于内存，进程退出即消失，不写入磁盘；
- 登录成功后还会主动清除浏览数据；日志只记录主机名与路径，不含 ticket 等凭据。

## 运行环境（适用平台）

Windows 10 / 11（64 位）；需要 WebView2 运行时（Windows 11 与安装过 Edge 的 Windows 10 已自带）。

## 数据时效（重要）

课表数据来自教务系统公开查询接口的**历史抓取快照**，不会自动同步。
教务系统后续若有调课、换教室、停开课等调整，本程序不会反映，**请以教务系统的实际安排为准**。
程序窗口顶部常驻提示条会标明数据库更新时间与数据覆盖范围。
